# Lucky Spin Wheel

Create a modern and attractive Spin the Wheel game with 10 colorful segments. Each segment should have a different reward:

1. ₹50 Cashback

2. Better Luck Next Time

3. Free Coffee

4. 10% Discount

5. ₹100 Cashback

6. Mystery Gift

7. Free Shipping

8. 20% Discount

9. Bonus Points

10. Grand Prize

Include smooth spinning animation, realistic sound effects, a glowing "SPIN" button in the center, confetti animation for winning prizes, and a responsive design suitable for desktop and mobile.
